Image Number Helper は、ウェブページ上のすべての画像に見やすい番号を付けます。デザインレビュー、QA、クライアントとの打ち合わせ、画像検索結果の比較で、「左のあれ」ではなく「画像 7」と言えるようになります。

無料
• どのページでも最初の 8 枚に番号を付けます。Alt+Shift+N を押すか、ツールバーのポップアップのスイッチをオンにします。
• 番号をクリックすると「画像 7」をコピー。画像を右クリック → 「画像番号をコピー」でもコピーできます。
• 番号を指定して画像へジャンプ：ページがその画像までスクロールして強調表示します。
• 番号のスタイルは 4 種類：1 2 3、A B C、01 02 03、I II III。
• 遅延読み込みの画像が増えても番号は変わりません。小さなアイコンや非表示の画像は除外されます（最小サイズは変更可能）。
• 選んだサイト、またはすべてのサイトで自動的にオンにできます。
• 対応言語：English、Español、Português (Brasil)、Deutsch、Français、日本語。

PRO：2.99 米ドル（買い切り・サブスクなし）
• すべてのページで番号付けは無制限
• 会議用レポート：各画像の代替テキスト、サイズ、ファイル名を Markdown / テキスト / CSV で出力。代替テキストがない画像も表示されます
• 番号付きスクリーンショットをワンクリックでクリップボードにコピーして保存
• 6 色、5 か所の位置（四隅と中央）、開始番号の変更
• 今後追加されるすべての Pro 機能を、すべての Chrome プロフィールで利用可能
バージョン 3 より前から Image Number Helper をお使いですか？初期ユーザーの方は、Pro をずっと無料でお使いいただけます。

使い方
1. インストール後、アイコンをツールバーにピン留めします。
2. 画像のあるページを開いて Alt+Shift+N を押すと、画像に番号が表示されます。
3. 番号をクリックしてコピーし、Slack、Figma のコメント、チケットに貼り付けます。
4. 任意：ポップアップの「アップグレード」から Pro を購入できます。支払い後は自動で有効になります。

プライバシー
アカウント不要、解析なし、トラッキングなし。設定と Pro ライセンスは Chrome の同期ストレージに保存されます。ページの内容が送信されることはありません。レポートとスクリーンショットは、クリップボードまたはダウンロードフォルダにのみ保存されます。Pro の支払いは Stripe が処理し、カード情報が当方に届くことはありません。ライセンスは端末上でオフライン検証されます。
