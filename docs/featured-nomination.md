# Chrome Web Store: Featured badge nomination

The Featured badge can't be bought. Google reviews nominations by hand, and the badge can help search ranking.
Only the extension's owner can submit this, from the Developer Dashboard.

## When to submit
After version 3.1.0 is live and the listing has some positive reviews. I found no published minimum, but a nomination
with a handful of good reviews is easier to say yes to than one with none. Resubmitting later is fine.

## Where
Developer Dashboard → **Support** (or the "?" help menu) → **One Stop Support** → choose the option about
nominating an extension for a **Featured** badge. The wording on the form changes from time to time; if you can't find it, pick
the closest "Chrome Web Store → my item" option and paste the text below.

## Text to paste

> Please consider **Image Number Helper** (item ID oblgohgggijhcpaaimpcnkajklhfkelf) for a Featured badge.
>
> It numbers every image on a web page so teams can say "image 7" instead of "the one on the left" in design reviews, QA and meetings.
>
> - **Privacy and safety:** Manifest V3, four low-risk permissions (storage, activeTab, contextMenus, scripting), no remote code, no analytics, no tracking. Page content never leaves the device. A public privacy policy, terms and refund policy are on the product website.
> - **Free to use:** the core feature (numbering, click-to-copy, jump-to-image) works with no account and no payment. An optional one-time Pro upgrade adds a report and screenshots.
> - **Polished and localized:** UI and store listing in six languages (English, Spanish, Portuguese-Brazil, German, French, Japanese), a light/dark-aware popup, keyboard shortcut (Alt+Shift+N), focus states and ARIA labels throughout.
> - **Complete listing:** five screenshots, promo tiles, a demo video, a support page and a documented release process.
>
> Website: https://image-number-helper-site-hecb.onrender.com

## Tips
- Don't ask for Featured in review replies or support threads. Use the form once.
- Keep the listing, screenshots and privacy answers in step with each release; stale details are a common reason for a "not yet".
- The **Established Publisher** badge is separate: it only needs your publisher identity verified in the dashboard's Account tab.
