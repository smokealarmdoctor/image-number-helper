# Posting kit (drafts only; you create the accounts and post)

Rules I followed in every draft:
- Value first: each post teaches something useful without the extension.
- You are the developer, and every post says so. Pro is described as a paid upgrade, once, at $2.99.
- One link per post. No fake reviews, no asking friends to upvote or rate.
- **Read each community's current rules before posting.** I could not open Reddit or the
  Chrome Web Store from this environment, so every subreddit rule below is unverified. If a
  community bans self-promotion, post the *article* (not the product) or skip it.

## One post a week, in this order

| Week | What | File |
|---|---|---|
| 0 (now) | Check the live store listing; make the YouTube demo public | `youtube.md` |
| 1 | dev.to article (canonical link to the site guide) | `devto-alt-text-audit.md` |

| 3 | r/webdev Showoff Saturday | `reddit-webdev-showoff.md` |
| 4 | r/seogrowth (self-post) | `reddit-seogrowth.md` |
| 5 | A photographers' forum, as a tip not an ad | `photographers-proofing.md` |

One per week so you can tell which one moved installs.

## How to tell whether a post worked (no analytics, by design)

1. Before posting, note today's real installs from the dashboard (**exclude Romania**: export
   "Installs by region" and ignore that column).
2. Two days after each post, export installs by date again and compare against the ~2/day baseline.
3. For the dev.to article and the site guide, Search Console > Performance shows impressions and
   clicks per page after a week or two.
4. Stop rule: if after weeks 1-4 real installs have not moved above ~5/day, stop promoting and
   tell me. That is a real answer, not a failure of effort.

## Things to say if asked

- *"Is it free?"* The first 8 images on every page, plus click-to-copy, jump-to-image and number
  styles. Pro ($2.99 once, no subscription) removes the limit and adds the report, numbered
  screenshots, colours and positions.
- *"Do you collect data?"* No account, no analytics, nothing leaves the browser. Pro uses
  Stripe checkout and an offline-checked licence key.
- *"Why numbers and not a feedback tool?"* It is a labelling aid for reviews you already do in
  Slack, Figma or a video call. It does not replace a tracker.
