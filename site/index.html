How it works

Press Alt + Shift + N on any page. That’s the whole setup.

Every image gets a number

Clean badges appear on top of each image without breaking the page or blocking clicks. Numbers stay put while more images load, and tiny icons are skipped.

Compare search results by number

Works on image search results, mood boards and marketplaces. “Number 9 or 16?” is a question everyone can answer.

Jump straight to any image

Type a number and the page scrolls to it and spotlights it. Click any badge to copy “Image 7” to paste into chat or a ticket.

A meeting-ready report PRO

Copy every number with its alt text, size and file name as Markdown, plain text or CSV. Images missing alt text are flagged for you.

Make it yours PRO

Six colors, five positions, four number styles (1, A, 01, I) and a custom start number, so badges stand out on any page.

Questions

Does it change or slow down websites?

No. Numbers are drawn in a separate overlay on top of the page. They don’t alter the page, block clicks, or load anything from the internet.

Do you collect my browsing data?

No. There’s no account, no analytics and no tracking. Settings sync through your own Chrome profile. See the privacy policy.

How do I get Pro after paying?

Click Upgrade in the extension and pay with Stripe. Pro unlocks automatically on the thank-you page. You’ll also see your license key there to use on other Chrome profiles.

I used the extension before Pro existed. Do I have to pay?

No. Everyone who installed it before version 3 is a founding user and has Pro free, forever.

Can I get a refund?

Yes, within 30 days, no questions asked. See the refund policy.

I lost my license key.

Contact support with the email you used at checkout and we’ll send it again.

Does it work in Edge, Brave or Arc?

It’s built for Chrome and installs from the Chrome Web Store. Most Chromium-based browsers can install Chrome Web Store extensions too.
