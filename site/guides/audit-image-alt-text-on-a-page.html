How to audit image alt text on any web page

Published November 23, 2026

An alt text audit answers one question for every image on a page: does a person who can’t see this image get what they need? It takes about ten minutes per page once you have a routine. This guide gives you the routine, a free snippet that works in any browser, and a way to report the results.

Step 1: list every image and its alt status

Open the page, open the browser Console (F12, then the Console tab), paste this and press Enter:

console.table([...document.images].map((img, i) => ({
  n: i + 1,
  alt: !img.hasAttribute('alt') ? 'MISSING' : img.alt === '' ? '(empty)' : img.alt,
  shown: img.width + '×' + img.height,
  file: (img.currentSrc || img.src).split('/').pop().split('?')[0].slice(0, 40)
})))

You get a table with one row per <img>: its position, its alt text (or MISSING / (empty)), its displayed size and its file name. Scroll the page to the bottom first so lazy-loaded images are included, then run it again.

Two limits to know about. The numbers here follow the page’s source order, so they will not always match the badges an extension draws on the screen. And it only sees <img> elements: images used as CSS backgrounds, inline SVG and <canvas> need to be checked by hand.

Step 2: sort each row into one of four groups

  • MISSING. No alt attribute. This is the real failure: screen readers may read out the file name instead. Every row here needs a decision.
  • (empty). alt="" tells assistive technology to skip the image. Correct for decoration, wrong for anything that carries meaning, such as a product photo or a chart. Look at each one.
  • Alt text that is really a file name, such as IMG_2041.jpg or hero-final-v3. It looks present but tells the reader nothing.
  • Alt text that is present but weak: “image”, “photo”, the same sentence repeated on every image, or a paragraph-long description of a simple icon.

Step 3: decide what each image needs

Ask what the image is for, not what it looks like:

  • Informs (photo, chart, diagram): a short description of the point it makes. For a chart, give the takeaway and put the data in the text nearby.
  • Acts (logo that links home, icon button): describe the destination or action, such as “Home” or “Search”, not the picture.
  • Decorates (divider, background flourish, a photo that only repeats the text beside it): alt="".

The W3C’s alt text decision tree walks through the same questions. Missing text alternatives fall under WCAG success criterion 1.1.1, Non-text Content.

Step 4: write the report so someone can act on it

A list of file names is hard to fix; a list of which image on which page is easy. For each finding record the page address, the image number, what it shows, the problem (missing, empty but meaningful, file name, weak) and the suggested alt text. In a meeting or a ticket, the image number is what lets everyone find the same image without describing it.
