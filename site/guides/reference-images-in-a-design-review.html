How to reference images in a design review

Published November 12, 2026

Design reviews go wrong in a predictable way: someone says “the photo on the left needs to be bigger,” and three people look at three different photos. A little structure removes the confusion.

Step 1: Number the images before the meeting

Open the page and switch numbering on, so every image has a visible number. With Image Number Helper that is Alt + Shift + N. Share your screen with the numbers showing, and nobody has to describe where an image is.

Step 2: Write feedback as a numbered list

Keep each comment short and start with the image number:

Image 3: crop tighter, the subject is cut off on mobile.
Image 7: swap for the product shot with the white background.
Image 9: alt text is missing.
Image 12: too heavy, compress before launch.

Anyone reading the list later can find each image without a screenshot.

Step 3: Attach evidence

  • A numbered screenshot shows exactly what the reviewer saw. The Pro version captures one in a single click.
  • A report lists every number with its alt text, size and file name, which turns “fix the images” into concrete tickets.

Step 4: Turn comments into tickets

Click a badge to copy “Image 7” and paste it into the ticket title. The number, plus the page address, identifies the image.

Avoid these traps

  • Numbers belong to one page view. They follow the order images are found, so they can differ between pages, screen sizes and after the content changes. Name the page and the screen size in your feedback.
  • Agree on one numbering style for the team, so “image 7” and “image G” aren’t mixed.
  • Renumber after big changes and say so in the thread.
